# DEVELOPMENT IMAGE STRATEGY

IMPORTANT

DO NOT generate AI images during development.

Instead use premium placeholder/editorial images from sources such as:

• Unsplash
• Pexels
• Royalty-free beauty photography
• Luxury fashion photography
• High-quality editorial lifestyle photography

Choose images that closely match the style, lighting, composition and mood of the uploaded template.

Never use:

❌ Cartoon artwork

❌ Low-quality stock photos

❌ Bright colorful business stock photos

❌ Random AI art

❌ Inconsistent image styles

--------------------------------------------------

# IMAGE REPLACEMENT STRATEGY

The website must be built so every placeholder image can later be replaced with AI-generated brand assets without changing the layout.

All image references should be centralized.

Never hardcode image URLs throughout the project.

Use semantic names.

Examples

hero-editorial

fragrance-banner

hair-care-editorial

collection-fashion

skincare-lifestyle

best-seller-1

newsletter-background

The layout should remain unchanged when replacing images.

6. Build incrementally.

7. Keep components reusable.

8. Explain major architectural decisions before implementing them.

Never rewrite working code without justification.
